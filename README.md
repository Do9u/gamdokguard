# 감독가드 설치 안내 (감독관용)

갤럭시 등 안드로이드 휴대폰 전용입니다. 아이폰에서는 설치되지 않습니다. 5분이면 됩니다.

## 0. 먼저 알아 두세요
- 이 앱은 **참고용 개인 도구**입니다. 경고가 떠도 그것만으로 부정행위를 판정하지 마세요. 반드시 직접 확인하세요.
- 앱은 인터넷 권한이 없고, 아무것도 송신하지 않습니다. 남의 기기 신호는 "듣기만" 하고(클래식 블루투스·WiFi는 안드로이드 표준 스캔), 남의 기기에 연결하지 않습니다. 관측 기록을 내보내는 기능은 없습니다.
- 플레이스토어 앱이 아니라서 설치할 때 경고가 몇 번 나옵니다. 아래 순서대로 하면 됩니다.

## 1. 파일 받기
1. 휴대폰으로 https://github.com/Do9u/gamdokguard/releases/latest 를 엽니다(유튜브 설명란 링크와 같습니다). 화면이 영어여도 괜찮습니다.
2. **Assets** 아래 파란 글씨 **`gamdokguard-vc26-release.apk`**를 누릅니다. 밑의 "Source code (zip/tar.gz)"는 누르지 마세요(설치 파일이 아닙니다).
3. "이러한 유형의 파일은 폰에 손상을 줄 수 있습니다" 창이 뜨면 출처가 `release-assets.githubusercontent.com`인지 보고 [다운로드]를 누릅니다.
4. 다 받아도 화면에 아무것도 안 뜰 수 있습니다. 화면 위에서 아래로 쓸어 알림의 파일을 누르거나, [내 파일 → 다운로드]에서 파일을 누릅니다.

진짜 파일인지 확인(가능하면): 버전 1.25. 이 페이지와 유튜브 설명란의 확인값이 같으면 원본입니다.
- 파일 확인값(SHA-256): `e091bf848277fc52ed5f5ed0cb75aa47997db56c284eec3fb9369b61e11e4eb5`
- 서명 확인값(인증서 SHA-256): `DF:F5:8D:4E:7D:04:7D:42:90:3F:27:90:FB:9F:9E:7C:0B:AE:2D:92:B4:20:5C:39:21:29:E8:4B:03:D2:AF:CC`
메신저·단체방에서 돌아다니는 다른 파일은 설치하지 마세요. 위 링크에서 직접 받은 파일만 쓰세요.

## 2. 설치
1. 받은 APK 파일을 누릅니다(알림, 또는 내 파일 → 다운로드).
2. **"출처를 알 수 없는 앱" 안내가 나오면**: [설정] → 지금 파일을 연 앱(예: 인터넷 브라우저, 내 파일)의 [이 출처 허용]을 켜고 뒤로 갑니다.
3. **삼성 "보안 위험 자동 차단"(자동 차단기)이 설치를 막으면**
   1. 설정 → 보안 및 개인정보 보호 → **보안 위험 자동 차단**. 안 보이면 설정 검색창에 "자동 차단".
   2. **"자동으로 켜기"**가 있으면 먼저 끄세요. 켜 두면 30분 뒤 저절로 다시 켜집니다(One UI 8.5 이상: S23~S25, Z Fold5~7·Flip5~7, A15~A56, Tab S9~S11 등).
   3. **최대 제한**이 켜져 있으면 끄고, 이어서 자동 차단을 끕니다(지문·PIN 확인).
   4. APK를 설치하고 앱이 열리는지 확인합니다. 곧바로 다시 켜지면 폰을 껐다 켠 뒤 2~3을 다시 합니다.
   5. 설치 후 자동 차단을 다시 켜도 됩니다. 단, **앱을 업데이트할 때는 다시 꺼야 합니다.**
   - 삼성 공식 안내: https://www.samsung.com/uk/support/mobile-devices/protect-your-galaxy-device-with-the-new-auto-blocker-feature/
4. **"Play 프로텍트" 경고가 나오면**: [세부정보 더보기] → [무시하고 설치](또는 [설치])를 누릅니다. "앱 검사 보내기"는 보내지 않아도 됩니다.
   - "이전 버전의 Android용으로 제작된 앱"(옛 안드로이드용 앱) 경고가 떠도 **설치를 계속**하면 됩니다.
   - 구글 공식 안내(Play 프로텍트 경고): https://developers.google.com/android/play-protect/warning-dev-guidance
5. [설치] → [열기].

## 3. 처음 실행
1. 앱을 열면 시작 버튼 없이 바로 스캔을 준비합니다.
2. 권한 창이 차례로 뜹니다. 모두 허용하세요.
   - 위치: **"정확한 위치"**를 켜고 [앱 사용 중에만 허용]. ("대략적인 위치"를 고르면 지금 버전은 스캔하지 않고 정확한 위치로 바꾸라고 안내합니다)
   - 근처 기기: [허용] (주변 블루투스 찾기용. 남의 기기에 연결하지 않습니다)
   - 전화 권한은 묻지 않습니다. 전화 권한을 달라는 창이 뜨면 받은 파일이 원본이 아닐 수 있으니 설치하지 말고 지우세요.
3. 휴대폰의 **위치(GPS) 기능과 블루투스, WiFi를 켜 두세요.** 꺼져 있으면 목록이 비어 보입니다. (WiFi는 공유기에 연결하지 않아도 켜져만 있으면 됩니다)

## 4. 시험 당일
- 앱 화면을 띄워 두세요. 앱이 열려 있는 동안은 화면이 저절로 꺼지지 않게 해 둡니다. 다른 앱으로 넘어가거나 전원 버튼으로 끄면 스캔이 멈출 수 있습니다.
- 배터리 절약 모드는 끄는 것을 권합니다.
- 화면 맨 위 "스캔" 묶음에 무선 종류마다 한 줄씩 나옵니다. 종류는 기호로 표시합니다(블루투스 기호 2줄: 저전력·클래식, 와이파이 기호). 줄마다 신호등, 스캔 주기, 마지막으로 들은 지 몇 초인지, 잡힌 개수가 나옵니다(예: "30초마다 · 12초 전 · 3개"): 초록=ON, 노랑=다시 켜는 중, 빨강=OFF(원인이 함께 뜹니다. 예: 블루투스 꺼짐).
- 색은 위험도입니다: 빨강=확실, 노랑=애매, 회색=무관. 막대는 기기마다 신호 세기(0~100)이고, 막대 아래 기호는 무선 종류(와이파이 · 핫스팟 · 블루투스 · 겹침)입니다. 막대를 누르면 아래 목록에서 그 기기 줄이 노랗게 선택됩니다(다시 누르면 풀림).
- 복도를 천천히 걷다가 교실 앞마다 잠깐 멈추세요. 스캔 묶음 아래 '위치' 줄에 '이동 중'/'정지'가 뜹니다. 새로 생기거나 세지는 신호가 단서입니다.
- 자력계 줄: 금속탐지기를 꺼내기 어려울 때(소리가 나거나 거창해 보일 때) 쓰는 조용한 대용입니다. 자석·스피커·금속 덩어리에 폰을 **수 cm까지** 가까이 대면 자력계 막대가 찹니다. 줄을 누르면 그 자리 값을 기준으로 다시 잡습니다. 책상 철제 다리·필통 자석에도 반응하고 조금만 떨어져도 안 잡히므로, 이것만으로 판단하지 마세요.
- 블루투스 저전력은 실시간, 클래식 블루투스는 2분마다 짧게, WiFi 목록은 안드로이드 제한 때문에 몇십 초 간격으로 새로 고쳐집니다.
- 목록에는 종류와 번호만 나옵니다(예: [이어폰] 3번). 기기가 밝힌 이름·모델·주소는 화면에 나오지 않습니다. 이름에 의심 낱말이 들어 있으면 그 낱말만 보입니다.
- 시작하기 전에 본인 이어폰·워치 등은 꺼 두세요. 켜 두면 내 기기가 목록에 섞입니다.
- 화면을 사진으로 찍어 단체방 등에 올리지 마세요. 직접 적은 메모가 보일 수 있습니다.

## 5. 문제가 생기면
| 증상 | 해결 |
|---|---|
| "권한 거부됨"이 뜨고 다시 눌러도 창이 안 뜸 | 화면의 [앱 설정]을 누르거나 [설정 → 애플리케이션 → 감독가드 → 권한]에서 위치(정확한 위치)·근처 기기를 직접 허용 |
| 목록이 비어 있음 | 위치·블루투스·WiFi가 켜져 있는지 확인(위치가 꺼져 있으면 앱이 위에 알려 줍니다). 블루투스를 앱 실행 뒤 켰다면 앱을 완전히 닫고 다시 열기 |
| 앱이 갑자기 꺼짐 | 앱을 완전히 닫고 다시 열기. 계속되면 앱을 지우고 위 링크에서 다시 받아 설치 |
| 설치가 "앱이 설치되지 않았습니다"로 실패 | 예전 버전이 다른 서명으로 깔려 있을 수 있음. 기존 앱을 지우고 다시 설치 |
